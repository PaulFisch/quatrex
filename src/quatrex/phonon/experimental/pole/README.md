# Analytic pole experiment

This package preserves the analytic pole treatment and its verification
oracles. It is not part of the default phonon solver.

The campaign found that warm bulk modes broaden, but a strongly mixed,
unresolved tail remains. The simple-pole decomposition also failed the
production conservation gates in several device runs. These results do not
support using it as a replacement for a resolved raw three-phonon calculation.

The implementation remains available for extraction studies, dense reference
comparisons and future representations that close the mixed pole-background
sector. The production configuration keeps it disabled.
