# `phonon_inputs` configurations, organised by structure family

```
configs/
├── si_primitive/   # Si FCC primitive cell variants (QE + VASP, DFPT + FD)
├── sinw/           # H-passivated <100> Si nanowires
├── genw/           # H-passivated <100> Ge nanowires (generated by setup_genw100)
├── sigenw/         # SiGe alloy nanowires (generated by setup_sige_nw)
├── cnt/            # Carbon nanotubes (periodic + finite segments)
├── chain/          # Finite linear Si chain — smallest test fixture
└── si_fc3/         # Si FC3-only configs (ground-truth, hiphive variants)
```

## Family contents

| Family | Files | Notes |
|---|---|---|
| **si_primitive** | `prim.yaml`, `prim_vasp.yaml`, `prim_largek.yaml`, `dfpt.yaml`, `legacy_conventional.yaml` | 2-atom FCC primitive cell. The DFPT route uses D3Q. `legacy_conventional.yaml` is the original 8-atom conventional cell from before the named configs. |
| **sinw** | `sinw100_d5a_vasp.yaml`, generated `sinw100_d{6,9}a_vasp.yaml` | H-passivated <100> SiNW. `setup_sinw100.py --diameter <Å>` generates new diameters. |
| **genw** | (generated by `setup_genw100`) | Same geometry, Ge instead of Si. |
| **sigenw** | (generated by `setup_sige_nw`) | Random Si→Ge substitution into a SiNW base. |
| **cnt** | `cnt33_vasp.yaml`, generated `cnt33_finite_n{N}_vasp.yaml` | Periodic CNT(3,3) and finite-length segments. |
| **chain** | `si_chain.yaml`, generated `si_chain_n{N}_auto.yaml` | Finite Si chain — minimal test system. |
| **si_fc3** | `fc3_si.yaml`, `fc3_hiphive_si.yaml`, `fc3_hiphive_prim.yaml` | Si FC3-only configs (no relax) for tensor-decomposition studies. |

## Migration note (post-refactor)

The 11 top-level `config_*.yaml` files were moved into this tree on the
refactor that introduced `finite_analysis/`. Hard cutover — no symlinks.
Anything that referenced `config_<name>_vasp.yaml` literally must update
to the new `configs/<family>/<name>_vasp.yaml` path. The `RUNBOOK`,
`examples/setup_*.py` defaults, `tests/`, and `phonon/README.md`
were updated as part of the refactor.
