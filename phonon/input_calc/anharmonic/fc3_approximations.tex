\section{Setup}
\label{sec:setup}
% ======================================================================

We consider the compact third-order force constant (FC3) tensor obtained
from a supercell finite-displacement calculation.  In the compact format
the first atom index is restricted to the primitive cell while the
remaining two run over the full supercell:
\begin{equation}\label{eq:fc3}
  \Phi_{\alpha\beta\gamma}(0\kappa,\; l'\kappa',\; l''\kappa'')
  = \frac{\partial^3 E}
         {\partial u_\alpha(0\kappa)\,
          \partial u_\beta(l'\kappa')\,
          \partial u_\gamma(l''\kappa'')}\,.
\end{equation}
After mass-weighting, we collect the indices into composite DOF labels
\begin{equation}
  a = (\kappa, \alpha), \qquad
  c = (l'\kappa', \beta), \qquad
  d = (l''\kappa'', \gamma),
\end{equation}
so that the object to approximate is a three-index tensor
\begin{equation}\label{eq:target}
  \Phi_{acd}\,, \qquad
  a \in \{1,\dots,\ndof\}, \quad
  c, d \in \{1,\dots,D\},
\end{equation}
with $\ndof = 3\,\nprim$ and $D = 3\,\nsuper = 3\,N_{\mathrm{cell}}\,\nprim$.
For a $2\times2\times2$ supercell, $N_{\mathrm{cell}}=8$ and $D = 24\,\nprim$.

The full tensor has $\ndof \times D^2$ entries, reduced by the exchange
symmetry $\Phi_{acd} = \Phi_{adc}$ to $\ndof \times D(D+1)/2$.
For Si ($\nprim = 2$) this gives $\ndof = 6$, $D = 48$, and $13\,824$
independent entries.

Our goal: represent $\Phi_{acd}$ with far fewer parameters while
controlling the relative Frobenius-norm error
\begin{equation}\label{eq:error}
  \varepsilon = \frac{\|\Phi - \tilde\Phi\|_F}{\|\Phi\|_F}\,.
\end{equation}

We compare four decomposition strategies, summarized in
\cref{tab:methods}.

% ======================================================================
\section{Approximation 1: Truncated SVD (Separable)}
\label{sec:svd}
% ======================================================================

\paragraph{Ansatz.}
For each external DOF $a$, define the $D \times D$ slice
$M_a = \Phi_{a,:,:}$.  Stack all slices into a single matrix
\begin{equation}\label{eq:mstacked}
  M_{\mathrm{stack}} =
  \begin{pmatrix} M_1 \\ \vdots \\ M_{\ndof} \end{pmatrix}
  \in \mathbb{R}^{\ndof D \times D}.
\end{equation}
A truncated SVD at rank $R$ gives
\begin{equation}\label{eq:svd}
  M_{\mathrm{stack}} \approx \sum_{r=1}^{R} \sigma_r\, \vc{u}_r\, \vc{v}_r^\top\,,
\end{equation}
which reshapes to the tensor approximation
\begin{equation}\label{eq:sep}
  \boxed{
    \tilde\Phi_{acd}^{\mathrm{SVD}}
    = \sum_{r=1}^{R} F_r(a,c)\; h_r(d)\,,
  }
\end{equation}
with $F_r(a,c) = [\vc{u}_r]_{aD + c}$ and $h_r(d) = \sigma_r [\vc{v}_r]_d$.

\paragraph{Properties.}
The Eckart--Young theorem guarantees optimality among rank-$R$
\emph{matrix} approximations of~$M_{\mathrm{stack}}$.  However, each
rank component costs $\ndof \cdot D + D$ parameters---one left vector of
length $\ndof D$ and one right vector of length $D$---so SVD is
\emph{not} optimal per parameter when the tensor has exploitable symmetry.
The decomposition is purely algebraic.

\paragraph{Parameter count.}
\begin{equation}\label{eq:svd-params}
  N_{\mathrm{param}}^{\mathrm{SVD}}(R) = R\,D\,(\ndof + 1)
  \;\sim\; \mathcal{O}(R\,\nprim^2)
  \quad\text{(at fixed $N_{\mathrm{cell}}$).}
\end{equation}

% ======================================================================
\section{Approximation 2: Partially Symmetric CP (PSCP)}
\label{sec:pscp}
% ======================================================================

\paragraph{Ansatz.}
Exploit the exchange symmetry $\Phi_{acd} = \Phi_{adc}$ with a
\emph{shared} internal mode $\vc{v}_r$ for both the $c$ and $d$ legs:
\begin{equation}\label{eq:pscp}
  \boxed{
    \tilde\Phi_{acd}^{\mathrm{PSCP}}
    = \sum_{r=1}^{R} d_r(a)\; v_r(c)\; v_r(d)\,.
  }
\end{equation}

\paragraph{Construction (algebraic).}
\begin{enumerate}
  \item Reshape $\Phi$ to $(\ndof) \times D^2$ and compute
        $\Phi_{\mathrm{flat}} \approx \sum_r \sigma_r\, \vc{u}_r\, \vc{w}_r^\top$.
  \item Each $\vc{w}_r \in \mathbb{R}^{D^2}$ reshapes to a symmetric
        $D \times D$ matrix~$W_r$ (guaranteed by $\Phi_{acd} = \Phi_{adc}$).
  \item Eigendecompose $\sigma_r W_r = Q_r \Lambda_r Q_r^\top$;
        each surviving eigenpair $(\lambda_{rp}, \vc{q}_{rp})$ yields
        \(
          d_{rp}(a) = [\vc{u}_r]_a \lambda_{rp},\;
          v_{rp}     = \vc{q}_{rp}.
        \)
\end{enumerate}
The total rank is $R_{\mathrm{total}} = \sum_r R_r$ where $R_r$ is the
number of retained eigenpairs.  Truncation is performed by sorting all
terms by $|\lambda_{rp}| \|\vc{u}_r\|$ and keeping the top~$R$.

\paragraph{Parameter count.}
\begin{equation}\label{eq:pscp-params}
  N_{\mathrm{param}}^{\mathrm{PSCP}}(R) = R\,(\ndof + D)
  \;\sim\; \mathcal{O}(R\,\nprim)
  \quad\text{(at fixed $N_{\mathrm{cell}}$).}
\end{equation}

% ======================================================================
\section{Approximation 3: Symmetric CP with Three Modes (SCP3)}
\label{sec:scp3}
% ======================================================================

\paragraph{Ansatz.}
The full (non-compact) FC3 tensor possesses $S_3$ permutation symmetry.
We exploit this with three independent modes per rank, symmetrized
over all permutations:
\begin{equation}\label{eq:scp3}
  \boxed{
    \tilde\Phi_{acd}^{\mathrm{SCP3}}
    = \sum_{\xi=1}^{R} \frac{\lambda_\xi}{6}
      \sum_{\sigma \in S_3}
      u^{\xi}_{\sigma_1}\!\bigl(p(a)\bigr)\;
      u^{\xi}_{\sigma_2}(c)\;
      u^{\xi}_{\sigma_3}(d)\,,
  }
\end{equation}
where $u^{\xi}_1, u^{\xi}_2, u^{\xi}_3 \in \mathbb{R}^D$ and
$p(a)$ maps the primitive-cell DOF index~$a$ to its supercell-DOF
counterpart in cell zero.

\paragraph{Construction.}
Optimization-based: minimize $\|\Phi - \tilde\Phi\|_F^2$
via Adam (1500~iterations) followed by L-BFGS with projected gradients.
The acoustic sum rule $\sum_j u^\xi_s(j,\beta) = 0$ is enforced by
projection after each step.

\paragraph{Parameter count.}
\begin{equation}\label{eq:scp3-params}
  N_{\mathrm{param}}^{\mathrm{SCP3}}(R) = R\,(3D + 1)
  \;\sim\; \mathcal{O}(R\,\nprim)
  \quad\text{(at fixed $N_{\mathrm{cell}}$).}
\end{equation}

% ======================================================================
\section{Approximation 4: Fully Symmetric CP (FSCP)}
\label{sec:fscp}
% ======================================================================

\paragraph{Ansatz.}
The most constrained decomposition: a single shared mode per rank,
\begin{equation}\label{eq:fscp}
  \boxed{
    \tilde\Phi_{acd}^{\mathrm{FSCP}}
    = \sum_{r=1}^{R} \lambda_r\;
      v_r\!\bigl(p(a)\bigr)\; v_r(c)\; v_r(d)\,,
  }
\end{equation}
with $v_r \in \mathbb{R}^D$.  No permutation sum is needed because the
symmetry is built in.  This is the symmetric tensor analogue of a
spectral decomposition.

\paragraph{Construction.}
Same optimization procedure as SCP3 (Adam~+~L-BFGS, ASR projection).

\paragraph{Parameter count.}
\begin{equation}\label{eq:fscp-params}
  N_{\mathrm{param}}^{\mathrm{FSCP}}(R) = R\,(D + 1)
  \;\sim\; \mathcal{O}(R\,\nprim)\,.
\end{equation}
Three times fewer mode parameters than SCP3 at the same rank, but the
constraint $u_1 = u_2 = u_3 = v$ limits the rank-1 terms to symmetric
outer products $v \otimes v \otimes v$, so higher rank may be needed.

\paragraph{Key observations.}
\begin{enumerate}
  \item \textbf{SCP3 dominates.}
        At $R=8$ (1\,160 parameters, 8.4\% of the full tensor),
        SCP3 already achieves $G$-error $< 0.05\%$.
        By $R=16$ the error is $\sim 10^{-5}$.

  \item \textbf{SVD is wasteful per parameter.}
        To reach ${\sim}1\%$ $G$-error, SVD needs $R=16$
        (5\,376 parameters), nearly 5$\times$ more than SCP3 at $R=8$.

  \item \textbf{FSCP has an accuracy floor.}
        Beyond $R \approx 16$, adding more rank-1 symmetric outer
        products $v \otimes v \otimes v$ does not substantially improve
        accuracy.  The single-mode constraint is too rigid.

  \item \textbf{PSCP converges slowly.}
        The two-stage algebraic construction (SVD then eigendecomposition)
        is not jointly optimal; $R=48$ terms are needed to reach 0.6\%
        $G$-error.

  \item \textbf{$S_3$ symmetry acts as physical regularization.}
        \Cref{fig:frob-vs-transport} shows that SCP3 achieves much
        smaller $G$-errors than other methods at the same Frobenius
        error.  The permutation-symmetric ansatz preferentially captures
        the components of the FC3 that matter for transport.
\end{enumerate}

\section{Scaling Analysis for Large Primitive Cells}
\label{sec:scaling}
% ======================================================================

For a fixed supercell multiplier $N_{\mathrm{cell}}$ (e.g., $2\times2\times2
= 8$), we have $D = 3 N_{\mathrm{cell}} \nprim$.  The parameter counts per
rank component scale as:
\begin{align}
  N_{\mathrm{param}}^{\mathrm{SVD}} / R
    &= D(\ndof + 1)
    = 9 N_{\mathrm{cell}} \nprim (3\nprim + 1)
    \sim \mathcal{O}(\nprim^2)\,,
    \label{eq:scale-svd} \\
  N_{\mathrm{param}}^{\mathrm{PSCP}} / R
    &= \ndof + D
    = (3 + 3 N_{\mathrm{cell}}) \nprim
    \sim \mathcal{O}(\nprim)\,,
    \label{eq:scale-pscp} \\
  N_{\mathrm{param}}^{\mathrm{SCP3}} / R
    &= 3D + 1
    = 9 N_{\mathrm{cell}} \nprim + 1
    \sim \mathcal{O}(\nprim)\,,
    \label{eq:scale-scp3} \\
  N_{\mathrm{param}}^{\mathrm{FSCP}} / R
    &= D + 1
    = 3 N_{\mathrm{cell}} \nprim + 1
    \sim \mathcal{O}(\nprim)\,,
    \label{eq:scale-fscp}
\end{align}
while the full tensor has $\ndof D^2 = 27 N_{\mathrm{cell}}^2 \nprim^3$
entries, i.e., $\mathcal{O}(\nprim^3)$.

\paragraph{Compression ratio at fixed rank.}
The compression ratio (full tensor entries divided by approximation parameters)
therefore grows with system size as:
\begin{equation}
  \frac{\ndof D^2}{N_{\mathrm{param}}}
  \sim
  \begin{cases}
    \mathcal{O}(\nprim) & \text{SVD}\,,\\
    \mathcal{O}(\nprim^2) & \text{PSCP, SCP3, FSCP}\,.
  \end{cases}
\end{equation}
The symmetric methods become \emph{quadratically} more efficient relative
to the full tensor as the primitive cell grows.

\Cref{fig:scaling-params} and \cref{tab:scaling} illustrate this for
a range of $\nprim$ at fixed representative ranks.

\paragraph{Practical implication.}
For a material with $\nprim = 64$ (e.g., a large oxide or ternary
compound), the full FC3 tensor has $4.5 \times 10^8$ entries.  SCP3 at
$R=8$ stores only 36\,872 parameters---a compression factor of
${\sim}12\,000\times$.  SVD at $R=8$ would need $2.4 \times 10^6$
parameters, providing only ${\sim}190\times$ compression.

Whether the required rank $R$ for a given accuracy grows with $\nprim$
is system-dependent and must be validated numerically for each material.
For the closely related harmonic force constants (FC2), the required rank
of similar decompositions is known to grow slowly (logarithmically to
sub-linearly) with system size for local interactions.

\section{Conclusions}
\label{sec:conclusions}
% ======================================================================

Among the four FC3 approximations:
\begin{itemize}
  \item \textbf{SCP3} (three-mode symmetric CP) offers the best
        accuracy-per-parameter trade-off and the strongest physical
        regularization.  It is the recommended method for transport
        applications where the fitted FC3 feeds into a self-energy
        kernel.

  \item \textbf{FSCP} (one-mode symmetric CP) uses fewer parameters per
        rank but hits an accuracy floor due to the overly constrained
        $v \otimes v \otimes v$ structure.

  \item \textbf{SVD} (separable) is the only method with a mathematical
        optimality guarantee (per rank), but its $\mathcal{O}(\nprim^2)$
        parameter scaling makes it impractical for large primitive cells.

  \item \textbf{PSCP} (partially symmetric) is algebraic and exploits
        $S_2$, but converges slowly due to the non-optimal two-stage
        construction.
\end{itemize}

All four methods scale as $\mathcal{O}(\nprim)$ or better per rank
component (vs.\ $\mathcal{O}(\nprim^3)$ for the full tensor), making
them viable for large systems.  The critical open question is how the
required rank scales with $\nprim$ for a target transport accuracy.
