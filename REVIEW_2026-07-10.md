## 2. Review findings (124 total; all high+med fixed or moot)

Multi-agent review over theory-consistency, correctness, efficiency/
GW-pattern, regularizer disposition and comment hygiene; substantive
findings adversarially verified or re-verified inline at the fix site.

High severity (all fixed):
- **Dense `retarded="fft"` kernel double-counted the bosonic mirror on
  full symmetric grids** (~200% error in Re Sigma^R; verified
  numerically, fixed, symmetric-grid path now matches the exact PV to
  grid resolution). All stored `d5a_T*_bubble_fft.npz` snapshots are
  tainted — flagged in MISSING.md for regeneration.
- **AndersonMixer solved its least squares on the rank-local Sigma
  slice** (multi-rank acceleration was not Anderson on the global
  vector); now MPI-reduced like the other mixers.
- **`rgf_dist.selected_solve` batching loop was dead** — compute blocks
  ran once on the last batch (silently wrong G for block-distributed
  multi-batch runs); loop restored, per-batch lead traces slice the OBC.
- **Heat-flow convergence gate NaN-poisoned** for `algorithm="inv"` /
  distributed RGF (NaN internal-interface sentinel entered the
  denominator; those runs could never converge). Lead-only denominator +
  NaN-aware spread.
- **SCP tadpole cluster**: wrong sign convention fed to `<uu>`
  (anti-stiffening), missing bosonic G^> fold (only n/(2n+1) of <uu>),
  missing 1/N_q mesh average, nnz-state pattern mismatch (crash at
  stack>1), np/xp mixing. Rewritten with a Tr<uu> > 0 guard.

Selected medium fixes: eta-ramp/IR-floor no longer leaks into the OBC
lead blocks (ideal-reservoir mandate); OBC regularizer sized from the
actual superblock; Broyden/RPM stall gates engaged quasi-Newton with an
empty residual window; Anderson warmup off-by-one; bubble-balance
diagnostic read zeroed G when `bubble_balance_check=false`; residual now
covers all three Sigma components; `get_batches` honors the memory cap;
grid guard (uniform, zero-based) on the bubble FFT; coupled-q mesh
validated against the Gamma-centered ordering; q-negated Hilbert mirror
for coupled-q under bias; `_assemble_kpoint` multi-k-axis indexing
(upstream bug); `transmission_q` default aligned to `retarded="fft"`;
band-top sampled off Gamma for the fmax guard; ballistic baseline
disables the SCP-tadpole FC3 copy; `converged` flag no longer misreports
edge cases; summarize.py gains the 1/N_q film normalization; figure-name
collisions removed (`prod_*`); plateau labels/ledger signs corrected.
Efficiency: reversed-leg FFTs reuse the forward transforms; coupled-q
vertex task list cached with pair dedup; ring pool exposed as
`sse_ring_threads`/`sse_ring_min_w` config options; `abort_residual` and
