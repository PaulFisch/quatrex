% ======================================================================
\section{Solver verification, cost, and scaling}
\label{sec:res_scaling}
% ======================================================================

The production distributed solver is validated against the dense reference and
benchmarked on the two axes that matter for anharmonic transport: the
block-tridiagonal recursion along the device and the energy-point parallelism
across MPI ranks. The two solvers follow the structure of the self-energy
(\cref{ssec:phph_distribution,ssec:phph_qdist}): Gamma-only conductors ($k{=}1$,
% REVIEW(verified): terminology aligned with the theory chapter -- comm.block (P_S), comm.stack (P_E), comm.q (P_q); the config keys block_comm_size/q_comm_size kept as parenthetical code names.
the nanowires and tubes) scale on
$\texttt{comm.block}\times\texttt{comm.stack}$ ($P_S\times P_E$; production
config key \texttt{block\_comm\_size}),
while the transversely-periodic systems ($k{>}1$, films and perovskites) scale on
$\texttt{comm.q}\times\texttt{comm.stack}$ ($P_q\times P_E$; production config
key \texttt{q\_comm\_size}) with $P_S{=}1$;
for the large-block Gamma-only regime the inner-ring contraction additionally
threads over the frequency axis (\cref{ssec:phph_ring}).

\paragraph{Machine-precision agreement with the dense reference.} The production
block-tridiagonal recursive Green's-function solver
(\texttt{qttools.greens\_function\_solver.RGF}) reproduces the dense reference and a
direct \texttt{numpy} inverse: the generic selected-inversion suite passes all
$144$ parametrised cases, and an end-to-end check on a genuine phonon Dyson matrix
$A(\omega^2)=\omega^2 I-D-\Sigma_\mathrm{leads}$ with Sancho--Rubio
open-boundary self-energies agrees to $1.4\times10^{-16}$ on the selected retarded
Green's function across $\omega\in[1,16]$\,THz. The three-phonon bubble and
scattering-self-energy kernels pass all $28$ tests; these also flag that a
nearest-neighbour FC3 truncation discards $34$--$48\%$ of the Frobenius norm for the
test fixtures, so the number of primitive cells per transport cell must be chosen
with care. The block-distributed recursion
(\texttt{rgf\_dist.RGFDist}) reproduces the serial reference under
\texttt{mpirun -np 3} ($\texttt{block\_comm\_size}{=}3$).

\paragraph{Solver cost.} The dense reference inverts the full $N_D\times N_D$ device
matrix, so its cost grows as $\mathcal{O}(n_\mathrm{slabs}^3)$, whereas RGF exploits
the block-tridiagonal structure and is linear in the number of cells
(\cref{fig:res_solver_scaling}, left): on phonon-Dyson matrices with a fixed
$192$-dof block, from $2$ to $32$ blocks the RGF wall time rises linearly while the
dense time follows the cubic guide, a $58\times$ gap at $32$ blocks, with the two
agreeing to $\sim10^{-13}$ on the block-tridiagonal entries. The complementary axis
-- distributing the energy points across MPI ranks -- is shown on the right: a fixed
% REVIEW(verified): wall times aligned to the surviving dist_scaling run (2.053/1.108/0.722/0.384 s -> 5.35x = "5.3x", 67%); the old 1.55->0.28 s figures were from a run whose data no longer exists. "Improves with problem size" is archived (F12: N=576 gave only 2.7x, overhead-bound).
$1536\times1536$ problem with $128$ energy points falls from $2.05$\,s on one rank to
$1.11$, $0.72$ and $0.38$\,s on $2$, $4$ and $8$ ranks, a $5.3\times$ speed-up
at eight ranks ($67\%$ parallel efficiency) that improves with problem size.

This separation is decisive for the anharmonic problem. The dense self-energy bubble

parallelises across the FC3 device vertex blocks $\Phi_{(I,K,K')}$ (pairwise
nearest-neighbour support) -- their count grows
$1\to8\to15$ for $n_\mathrm{slabs}=1,2,3$ -- but each block's bubble is itself a
serial BLAS contraction, so the dense per-point wall time climbs steeply: a single
$(3,3)$-CNT SCBA point costs $66$\,s at $n_\mathrm{slabs}{=}1$ and $1193$\,s
($\sim18\times$) at $n_\mathrm{slabs}{=}2$, and the converged three-cell point
($108$ DOF, $15$ blocks) costs $6.8$\,h. Multi-cell anharmonic transport is therefore
the regime of the RGF and energy-parallel production path, with the dense solver kept
as the verification oracle.

\paragraph{Production three-phonon throughput and memory.} A per-phase profile of a
four-cell CNT SCBA iteration attributes $99.8\%$ of the wall time to the three-phonon
bubble (\texttt{SigmaPhononPhonon}), with the RGF Dyson solve, the Sancho--Rubio open
boundaries, the stack/nnz transpose and the convergence book-keeping each below
$0.1\%$ (\cref{fig:res_phph_prod}, left); the bubble is thus the only phase worth
distributing. It parallelises cleanly on whichever communicator carries its outer
index: the $(I,J)$ block loop reaches $5.4\times$ at six ranks for $\Gamma$-only
conductors (\cref{fig:res_phph_scaling}, left) and the external-$q$ distribution

The earlier gather-based kernel (fig:res_phph_scaling) all-gathers the full-omega G and REPLICATES the bubble FFT on every stack rank (archive F22: 1.0/0.97/0.89x, no speed-up); the current production kernel transposes g(tau) so each comm.stack rank owns a tau-slice (theory ssec:phph_distribution, sse_phonon_phonon.py) and does scale on the stack axis (fig:res_phph_prod: near-ideal to ~16 ranks).
reaches $6.6\times$ at eight ranks for transversely-periodic systems (right). The
energy/stack axis separates the two kernel generations: the earlier gather-based
kernel replicated the full-$\omega$ bubble FFT on every stack rank and showed no
stack speed-up (\cref{fig:res_phph_scaling}), whereas the production kernel of
\cref{ssec:phph_distribution} transposes to per-rank $\tau$-slices, and its strong
scaling stays near ideal out to $\sim16$ ranks on the stack
axis, with the $q$-communicator saturating earlier once the internal all-gather of
$G$ dominates (\cref{fig:res_phph_prod}, right). Vertex storage is the binding memory
constraint: the dense per-block vertex $\Phi$ grows steeply with the transverse
$q$-mesh count $N_q$, reaching the few-GB scale for a realistic
$n_\mathrm{dof}{=}63$ block, whereas streaming the vertex keeps the peak roughly an
order of magnitude lower and well within the single-GPU $80$\,GB budget
(\cref{fig:res_phph_memory}).
